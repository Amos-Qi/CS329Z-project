# Study materials

Planned contents (docs/design.md §9):

- `protocol.md`: session script (consent → tutorial → trace-inspection → intervention → questionnaires).
- `probes.md`: probe questions per trace and probe point (current goal, completed changes, downstream effects, error origin).
- `rubric.md`: scoring rubric, fixed before the main study; double-code a subset and report agreement.
- `consent.md`: consent form, once the IRB question is settled with course staff (design Q8).
- Questionnaires: SUS and NASA-TLX.

Keep participant data out of the repo.
